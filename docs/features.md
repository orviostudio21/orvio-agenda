# Funcionalidades e regras

Clientes, catálogo de serviços e agendamentos por profissional. O fim é calculado pela duração do serviço e preservado como snapshot. Sobreposição do mesmo profissional é bloqueada; horários adjacentes são aceitos; cancelados liberam o horário. Os nomes de profissionais são normalizados. O preço combinado é independente do catálogo. Estados agendado, confirmado, concluído e cancelado. O agendamento usa o fuso America/Sao_Paulo.

Todos os dados pertencem a uma conta individual. Consultas, edição, exclusão, exportação e relações são limitadas ao proprietário. Contas novas começam vazias; exemplos fictícios são opcionais e não sobrescrevem dados.
